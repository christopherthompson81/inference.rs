---
title: 3D shapes from an image
description: JoVox generates the 64^3 voxel structure of the object in one image and TRELLIS.2's second stage meshes it; BiRefNet removes the background first.
---

`inference voxels` turns one image of an object into its 3D shape in two stages. JoVox, a discrete flow-matching
model, generates the object's occupancy at 4^3, 16^3 and 64^3 in one model, conditioned on the image through DINOv3.
TRELLIS.2's second stage then fills that structure with shape latents under the same image at 1024^2, decodes them to
a 1024^3 flexible dual grid and extracts a mesh, its small holes filled and its faces reduced to at most a million.
`--no-mesh` stops at the voxel structure.

| DINOv3 ViT-L/16 | [facebook/dinov3-vitl16-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m) | DINOv3 License (gated: request access on the page, then `inference login`) |
| BiRefNet | [ZhengPeng7/BiRefNet](https://huggingface.co/ZhengPeng7/BiRefNet) | MIT |
| TRELLIS.2-4B (shape flow and decoder) | [microsoft/TRELLIS.2-4B](https://huggingface.co/microsoft/TRELLIS.2-4B) | MIT |

Each is fetched into the Hugging Face cache on first use unless its folder is given (`--jovox`, `--dinov3`,
`--birefnet`, `--trellis2`). BiRefNet is only fetched for an image that needs its background removed, and of
TRELLIS.2-4B only `pipeline.json` and the two checkpoints the shape stage reads (3.5 GB).

## Run it

```bash
# an object on a transparent background is used as it is; any other image has its background removed
inference voxels --image chair.jpg --out chair/

# local checkpoints, another sample
inference voxels --image chair.png --out chair/ --jovox JoVox-64 --dinov3 dinov3-vitl16 --seed 3
```

| Flag | Default | Meaning |
|---|---|---|
| `--seed` | 0 | The sampler's seed; an image can have more than one plausible structure, and seeds pick among them |
| `--steps` | 72 | Sampling steps, 36 to 108 (the range the model was trained on) |
| `--cfg` | 1.5 | Classifier-free guidance, at least 1 |
| `--temperature` | 0 | 0 takes each cell's most likely occupancy; above 0 samples it |
| `--fill` | 0.74 | The share of the prepared image the object's longest side fills |
| `--remove-background` | off | Run BiRefNet even when the image has transparency of its own |
| `--no-mesh` | off | Stop at the voxel structure |
| `--cpu` | off | Run on the CPU (slow) |

On an RTX 3090 a structure takes 6 to 11 seconds (more voxels, more time) and about 6 GB of VRAM; meshing it adds
about 30 seconds (the shape flow ~14 s, the decoder ~1.5 s, hole filling and simplification on the CPU ~7 s) and takes
the peak to about 9.5 GB.

## Outputs

```
chair/
  prepared.png   what the model sees: the object cut out, centered and scaled to 512 x 512
  voxels.ply     the occupied cells as a cube mesh (only faces between filled and empty cells)
  mesh.ply       the surface: triangles, at most 1M faces
  meta.json      voxel count, mesh counts, settings and timings
```

Both sit in the unit cube centered on the origin, z up: voxel `(x, y, z)` spans `(x, y, z) / 64 - 0.5` to
`(x + 1, y + 1, z + 1) / 64 - 0.5`. The mesh is geometry only (no texture or vertex colors).

## As a server job

A server started with `inference serve` takes the same run as a job:

```bash
curl localhost:1234/v1/jobs -F 'request={"kind": "voxels", "seed": 3}' -F file=@chair.jpg
```

The request may also set `steps`, `cfg_strength`, `temperature`, `fill` and `remove_background`. The job's outputs are `voxels/voxels.ply`, `voxels/prepared.png` (also its preview) and `voxels/meta.json`. With
`--world-models <folder>`, checkpoints found there as `JoVox-64`, `dinov3-vitl16-pretrain-lvd1689m` and `BiRefNet` are
used instead of fetching them.
