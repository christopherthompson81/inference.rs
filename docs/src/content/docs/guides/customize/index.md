---
title: Customize
description: Adapters, chat templates, and sampling behavior.
---

Control how a model loads and generates:

- [LoRA and AnyMoE](/guides/customize/lora-adapters/) - attach fine-tuned adapters or compose experts at inference time.
- [Adapters from merged fine-tunes](/guides/customize/adapters-from-merged-fine-tunes/) - recover the LoRA inside a full-weight fine-tune and serve it on a shared base.
- [Chat templates](/guides/customize/chat-templates/) - override the prompt format when auto-detection is wrong.
- [Sampling parameters](/guides/customize/sampling/) - temperature, top-k/top-p/min-p, penalties, and DRY.
