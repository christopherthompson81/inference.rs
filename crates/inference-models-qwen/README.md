# `inference-models-qwen`

Qwen models: the Qwen2, Qwen3, Qwen3-MoE and Qwen3-Next text models, and Qwen2-VL, Qwen2.5-VL, Qwen3-VL (dense and MoE), Qwen3.5 (dense and MoE), MiniCPM-o and Muse-Glimmer; Qwen3.5 drafts with `inference-drafters`' DFlash and DSpark models. Built on `inference-nn`; loaded through `inference-core`.
